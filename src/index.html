Импорт готовой сборки

Поддерживаются архивы .mrpack и .zip, а также папки из Prism, MultiMC и других лаунчеров. Исходные файлы не изменяются.

Выбери архив модпака или папку экспорта. Можно также перетащить файл в окно лаунчера.

A

Модпаки ATLauncher

Открой каталог ATLauncher в браузере. После скачивания поддерживаемый архив или экспортированную папку можно добавить через «Импорт».

C

Модпаки CurseForge

Перейди в каталог CurseForge. Поддерживаемый экспортированный ZIP можно импортировать через вкладку «Импорт».

FTB

Модпаки FTB

Выбери модпак на официальном сайте FTB. End Launcher пока не устанавливает закрытые манифесты напрямую; используй совместимый экспорт или перенос папки через «Импорт».

FTB

FTB Legacy

Для старых сборок FTB используй официальный каталог и затем импортируй доступную папку или архив. Автоматическая установка старых FTB-пакетов пока не поддерживается.

FTB

Импорт из приложения FTB

Выбери экспортированную папку экземпляра или поддерживаемый архив из FTB App. Исходная сборка останется нетронутой.

M

Модпаки Modrinth

Открой каталог Modrinth, скачай файл .mrpack, а затем импортируй его через вкладку «Импорт».

T

Модпаки Technic

Открой каталог Technic. End Launcher не загружает пакеты Technic автоматически; для совместимых экспортов используй «Импорт».

MODRINTH

Совет: сначала выбери сборку на главной странице. Устанавливай моды только для подходящей версии игры и загрузчика.

моды качаются прямо в папку mods (в том числе кнопкой Download во встроенном браузере) вместе с обязательными зависимостями (например, Fabric API); версия игры и загрузчик проверяются автоматически. Запускать сборки умеют Vanilla и Fabric.

Скачали мод где угодно? Просто перетащите файл .jar в окно лаунчера — он попадёт в mods выбранной сборки (совместимость проверится сама).

БЕЗОПАСНОСТЬ · END SHIELD

          

            
⬡
End Shield · проверка источника и обновлений
Проверяет доступность официального репозитория и ищет новый релиз. Это пока не полноценный антивирус и не подтверждение целостности установленных файлов.

            

              
              
              
            

            

            
Статус: проверка ещё не запускалась. Файлы лаунчера пока не сверены с подписанным манифестом.

            
End Shield не удаляет файлы и не загружает их третьим лицам. Для надёжной проверки подмены понадобится подписанный манифест релиза; изменение файла само по себе не доказывает заражение.

          


          
ИНТЕРФЕЙС

          

          
          
          
          
End Lite отключает декоративные эффекты и уменьшает число фоновых частиц. Он не ограничивает память Minecraft и не заменяет оптимизацию самой игры.

          

            Раскладка меняется сразу и запоминается. Для полного применения можно перезапустить интерфейс;
            это не перезапускает Minecraft и не удаляет настройки.

АККАУНТЫ

          
Выбор способа запуска перенесён на главное меню. Входы Microsoft и Ely.by можно настроить здесь.


          
ELY.BY

          

          

            

              
              
            

            

              
              
            

          

          
          

            Пароль уходит только на authserver.ely.by и нигде не сохраняется — лаунчер хранит лишь токен.
            Скины и серверы Ely.by работают через authlib-injector (скачается сам при первом запуске).
          


          
MICROSOFT

          

          

            
            
          

          

          

            
            
          

          

            Для входа нужно своё приложение в Azure (портал Azure → App registrations → Personal Microsoft
            accounts only → Authentication → Allow public client
            flows = Yes) и одобрение Mojang: aka.ms/mce-reviewappid.
