# 🐉 End Launcher

[English](README.md) · **Русский**

Лаунчер Minecraft в мрачном стиле Края. Устанавливает и запускает **Java Edition** (Vanilla, Fabric, Forge, NeoForge), качает моды с **Modrinth** с автоматической проверкой версии и загрузчика, сам находит или скачивает нужную **Java** и имеет необязательного **ИИ-помощника** для разбора крашей.

## Импорт сборок из других лаунчеров (V0.4.0)

Открой библиотеку End Launcher и нажми **«⇩ Импорт»**, чтобы увидеть подсказку, затем перетащи исходный файл или папку прямо в окно:

- **Modrinth** — файл `.mrpack`: End Launcher читает `modrinth.index.json`, копирует `overrides`/`client-overrides`, загружает клиентские файлы по HTTPS и проверяет SHA-1, если он указан в манифесте.
- **End Launcher** — экспортированный ZIP с `instance.json` и папками сборки.
- **CurseForge** — ZIP с `manifest.json`: переносит версию, загрузчик и содержимое `overrides`. В таком экспорте часто находятся только ID модов, а не сами `.jar`, поэтому их может понадобиться установить отдельно.
- **Prism/MultiMC и XMCL** — перетащи папку конкретного экземпляра (для Prism — папку, где лежит `.minecraft` и `mmc-pack.json`; для XMCL — папку с `instance.json`).
- **Отдельные `.jar`** всё ещё импортируются как моды в активную сборку.

Импорт создаёт новую копию внутри каталога End Launcher и не удаляет исходные файлы. Переносятся моды, конфиги, миры, ресурспаки, шейдеры и часть пользовательских настроек; Java, глобальные библиотеки и версии Minecraft переустанавливаются/подготавливаются самим End Launcher. Аккаунты, токены и настройки Java стороннего лаунчера не копируются. Импорт Quilt пока отклоняется, так как запуск Quilt ещё не поддерживается.


## Возможности

- **Java Edition**: клиент, библиотеки и ресурсы скачиваются и проверяются; версии от 1.7 до последнего релиза.
- **Автоматическая Java**: берёт подходящую из системы или скачивает официальную сборку Mojang под выбранную версию.
- **Загрузчики**: Vanilla, Fabric, Forge, NeoForge, ставятся одним нажатием «Играть».
- **Полноценная главная**: сначала показываются сборки и краткая статистика; популярные моды загружаются при появлении своего блока на экране, а патчноуты Minecraft — по необходимости.
- **Сборки (instances)**: у каждой сборки своя версия игры, загрузчик, моды, сохранения и настройки; библиотеки и ресурсы общие. Меню «⋯» на сборке открывает её моды, папку, переименование и удаление; также можно создать независимую копию сборки или экспортировать её содержимое в ZIP.
- **Моды, ресурспаки, шейдеры (Modrinth)**: результаты видны сразу (сначала самые популярные) и обновляются по мере ввода; установка в один клик, обязательные зависимости (например Fabric API) и проверка совместимости по версии игры и загрузчику. Встроенный браузер открывает любые сайты (Modrinth, CurseForge и др.) и кладёт скачанные `.jar` прямо в папку `mods` выбранной сборки; файлы с Modrinth проходят ту же проверку совместимости. Удобнее свой браузер? Скачайте мод где угодно и перетащите `.jar` в окно лаунчера: он попадёт в `mods` выбранной сборки и проверится так же.
- **Менеджер модов**: включить, выключить, удалить и обновить установленные моды.
- **Три способа входа**: офлайн-ник, Microsoft, Ely.by (со скинами и серверами Ely.by).
- **Играть вместе (P2P)**: друг заходит в ваш мир напрямую, без проброса портов. Это туннель только для Minecraft (не виртуальная сеть вроде Hamachi или Radmin).
- **Запуск Bedrock Edition** (Windows, если установлен).
- **ИИ-помощник (по желанию)**: разбирает краш-логи локально или через облако с вашим ключом; локальные компоненты скачиваются только по кнопке. Для слабых ПК его можно выключить полностью.
- **Мой остров**: на главной медленно вращается летающий островок из блоков. Стройте свой дом (11 видов блоков, есть кнопка «Домик»), а котик и собачка бегают по острову и запрыгивают на блоки. Всё сохраняется само.
- **Питомец** (котик, собачка, лиса, кролик, черепашка или ваша картинка / GIF) гуляет по низу окна, отзывается на клики и перетаскивается. Анимация лёгкая, а при выключенных анимациях он стоит на месте.
- **Красивые списки выбора**: выпадающие списки и переключатели нарисованы в цветах темы вместо системных белых окошек; в длинных списках (версии игры) есть поиск.
- **Плавный и лёгкий интерфейс**: боковое меню выезжает при наведении мыши (можно выключить), анимации страниц и карточек только на «дешёвых» для видеокарты свойствах и переключатель, который отключает все анимации и фоновые эффекты для слабых ПК.
- **Оформление**: 4 темы в стиле Края и своя палитра, переключаемые раскладки интерфейса: End, а также стили, вдохновлённые Modrinth App, Prism Launcher, TL Legacy, GDLauncher Carbon, Minecraft Launcher, ATLauncher и Lunar Client; это не их оригинальные логотипы или код, проект с ними не связан. В библиотеке есть поиск по сборкам и переключение «карточки / список».
- **Дополнительно**: лимит памяти, свои JVM-аргументы, своя Java; экспорт выбранной сборки в ZIP хранится в папке настроек `exports`.
- **Уведомление об обновлении**: баннер появляется, когда здесь выходит новый релиз.

## Установка

Скачайте установщик для своей системы на странице [Releases](https://github.com/Noyclic/End_Launcher/releases). Сборки не подписаны, поэтому Windows SmartScreen может показать предупреждение.

## Вход в аккаунт

| Способ | Что нужно |
|---|---|
| Офлайн | ничего (только ник; работает на серверах в офлайн-режиме) |
| Ely.by | бесплатный аккаунт на [Ely.by](https://ely.by) |
| Microsoft | сборка с одобренным Mojang ID приложения (см. ниже) |

Пароль никогда не сохраняется. Токены входа и необязательный ключ Groq кладутся в системное хранилище (Диспетчер учётных данных Windows, связка ключей macOS), если оно доступно; иначе (Linux или отказ хранилища) они лежат в файле настроек в слегка обфусцированном виде. Подробнее: [PRIVACY.md](PRIVACY.md).

## ИИ-помощник (по желанию)

- **Локально** (Микро / Продвинутый): на странице ИИ нажмите кнопки загрузки (движок [llama.cpp](https://github.com/ggml-org/llama.cpp) — только Windows, модели — с Hugging Face (unsloth / bartowski, есть запасные ссылки)) или положите `llama-cli` в `<config>/ai/bin`, а модель GGUF в `<config>/ai/models` сами. Модель загружается в память только на время ответа.
- **Облако** («Эндер-Мозг»): вставьте бесплатный ключ [Groq](https://console.groq.com) в Настройках. Отправляется только текст, который вы сами передали.
- Настройки → *ИИ-помощник* выключает всю функцию.

`<config>` — это `%APPDATA%/end-launcher` на Windows и `~/.config/end-launcher` на Linux.

## Играть вместе (P2P)

Значок 🌐 в правом верхнем углу: один игрок открывает комнату, друг вставляет код у себя и заходит в игре на `localhost:<порт>`. Нужна одна и та же версия игры.

- Хозяин открывает мир «для сети» (или запускает сервер); лаунчер сам находит порт в логе игры и предупреждает, если на нём никто не слушает.
- **Универсальный код**: лаунчер друга пробует три способа по очереди: прямой TCP через UPnP (никаких серверов), потом тикет iroh (relay + прямые адреса, DNS не нужен: для сетей, где DNS iroh блокируется), потом Node ID iroh (поиск через публичный DNS iroh). Отдельные варианты тоже показаны, а кнопка 📨 копирует готовое приглашение с инструкцией.
- Код комнаты — ключ доступа, а тикет ещё и содержит ваши IP-адреса: передавайте их только друзьям. Гости могут добраться только до выбранного вами порта игры.
- Трафик идёт напрямую между игроками, а если не получается — через публичные relay-серверы iroh. При закрытии лаунчера комната закрывается, а проброс порта на роутере убирается.
- P2P входит в сборку по умолчанию; чтобы собрать без него — `--no-default-features`.

## Сборка из исходников

Нужны [Node.js](https://nodejs.org) 20+, [Rust](https://rustup.rs) и [зависимости Tauri](https://v2.tauri.app/start/prerequisites/) (на Windows достаточно Visual Studio Build Tools и WebView2).

```bash
npm install
npm run dev      # запуск для разработки
npm run build    # установщики в src-tauri/target/release/bundle
```

Интерфейс — обычные HTML/CSS/JS в `src/`; всё остальное (установка, запуск, моды, вход) — Rust в `src-tauri/src/`.

### Настройка своей сборки

- **Уведомление об обновлении**: укажите `GITHUB_REPO` в `src-tauri/src/update.rs` в виде `ваш-ник/ваш-репозиторий`.
- **Вход через Microsoft**: зарегистрируйте приложение в Azure (Microsoft Entra ID → App registrations → *Personal Microsoft accounts only*, включите *Allow public client flows*), подайте его на одобрение Mojang по ссылке <https://aka.ms/mce-reviewappid>, затем впишите Client ID в Настройки → Аккаунт или зашейте в `src-tauri/src/auth.rs`. До одобрения вход через Microsoft вернёт «Invalid app registration»; офлайн и Ely.by работают всегда.

## Если что-то не работает

**Linux**
- Самый надёжный пакет — `.deb` (Debian, Ubuntu, Mint). Для `.AppImage` нужен FUSE 2 (`sudo apt install libfuse2`; в Ubuntu 24.04 — `libfuse2t64`); он собран на Ubuntu 22.04, поэтому на очень новых и очень старых системах лучше `.deb`/`.rpm`.
- Нужен WebKitGTK 4.1 (`libwebkit2gtk-4.1-0`). Для эмодзи (питомец и остров) нужен цветной шрифт: `sudo apt install fonts-noto-color-emoji`. `.deb` ставит всё это сам.
- Пустое окно или ошибки EGL на NVIDIA / Wayland: лаунчер уже отключает DMABUF-рендерер WebKit. Нужно старое поведение — запустите с `END_LAUNCHER_GPU=1`.
- Самой игре нужны OpenAL (`libopenal1`) для звука и рабочие драйверы OpenGL. На Linux ARM официальной Java от Mojang нет: поставьте Java сами (Настройки → Дополнительно → путь к Java).
- В изолированных пакетах (Flatpak/Snap) может не быть вашей Java или не работать `xdg-open`.

**macOS**
- Приложение не нотаризовано. Если macOS пишет «повреждено» или «неизвестный разработчик»: правый клик → «Открыть» или `xattr -dr com.apple.quarantine "/Applications/End Launcher.app"`.

**Windows**
- SmartScreen может предупредить, потому что сборка не подписана: «Подробнее → Выполнить в любом случае».

**Тормозит на старом ПК?** Настройки → Интерфейс → выключите «Анимации» (остановит остров, питомца и фоновые частицы).

**Остальное**: Настройки → Диагностика → «Скопировать сведения для баг-репорта» и вставьте текст в [issue на GitHub](https://github.com/Noyclic/End_Launcher/issues). Если лаунчер падал, приложите `crash.log` из папки настроек.


## End Shield: подлинность релизов

End Shield умеет проверять подпись Ed25519 манифеста релиза, опубликованного вместе с релизом на GitHub. В манифесте перечислены файлы релиза и их SHA-256-хеши. Действительная подпись подтверждает, что манифест подписан владельцем закрытого ключа проекта.

**Границы защиты:** эта версия проверяет только подпись манифеста. Она не сканирует компьютер на вирусы и пока не сравнивает каждый установленный файл лаунчера с манифестом. Действительная подпись не гарантирует отсутствие вредоносного кода.

Подробнее о данных и сетевых запросах — в [политике конфиденциальности](PRIVACY.md).

### Режим End Lite
В **Настройки → Интерфейс** включи «End Lite», если компьютер слабый или лаунчер заметно нагружает систему. Режим отключает декоративные эффекты интерфейса. Он не ограничивает память, выделенную Minecraft: её можно настроить отдельно.
